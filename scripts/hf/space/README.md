# DP2 x Euclid viewer - PRIVATE

Browses the private preview dataset of the DP2-cutouts project (Rubin DP2 x Euclid Q1): D1 isolated galaxies and
D2 Rubin blends with the Euclid target before / after masking its neighbours. **Shows Rubin DP2 pixels: keep this
Space private (Rubin data-rights holders only).**

Settings of the Space: variable `DATASET_REPO` (the private dataset repository), secret `HF_TOKEN` (a read token
that can see it). Code: `scripts/hf/space` of the DP2-cutouts repository.
